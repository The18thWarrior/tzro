# Semantic Validator

The Semantic Validator is a deterministic boundary seam injected by the Kahn Compiler as an explicit DAG node. It replaces strict JSON GBNF parsing by parsing loose, high-speed XML outputs from the Local Model and coercing them into the strict JSON parameters required by tool schemas.

## Responsibilities
- Parses XML generated by the Local Model.
- Implements type coercion (e.g. converting a string `"123"` into an integer `123`).
- Handles default imputation for missing optional fields.
- Triggers a deterministic retry loop by returning error strings back to the Local Model if parameter extraction critically fails.

## Why
This architecture relieves the Local Model of computing dense grammar masks for deeply nested JSON tool schemas, vastly increasing decoding speed while improving parameter correctness (see [ADR-0028: Semantic Validator Seam](../../adr/0028-semantic-validator-seam.md)).
