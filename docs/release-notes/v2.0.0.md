# Tzro v2.0.0 Release Notes

**Release Date**: 2026-08-27

---

## ✨ New Features

- **5-Harness Agent Hook Bridge** — Connect Tzro to Antigravity, Claude Code, Hermes, GitHub Copilot, and Pi-Coder with native lifecycle hooks that auto-compact tool outputs before they enter agent context. Use `tzro hook [harness] [event]` or let `tzro init` auto-detect and configure everything.

- **Tabular Data Engine** — Import CSV, TSV, or JSON array data into local SQLite with `tzro ingest`, then query it with SQL via `tzro query`. Agents get a compact data envelope with schema and sample rows instead of dumping the full dataset into context — 97%+ token reduction on data workloads.

- **Hook Auto-Installer** — Run `tzro init` to auto-detect active agent environments and configure lifecycle hooks with a single command. Supports `--hooks all` to force-configure all harnesses, and `--workspace` for project-scoped hooks.

- **Pi-Coder Integration** — First-class hook support for Pi-Coder's TypeScript-based tool interception protocol, including pre-tool and post-tool event handling.

- **KV-Cache E2E Benchmarks** — End-to-end benchmarks proving the KV-cache prefix lock guard improves cache effectiveness by 5–10 percentage points over native provider caching, tested across GPT-5.6 Luna and MiniMax via OpenRouter.

- **Marketing Website** — Go-based static website server for the Tzro landing page and documentation at `website/main.go`.

## 🔧 Improvements

- **KV-Cache Prefix Lock Guard** — Updated performance metrics: benchmarked at 70–99% cache read hit rates across 8 LLM providers via OpenRouter. Protects against the 12.5× cache miss penalty.

- **Tree-Sitter AST Skeletonizer** — Refined language support across Go, TypeScript, JavaScript, Python, and other Tree-sitter-supported languages. Achieves 70–90% token reduction on typical source files.

- **DLP Secret Masking** — Improved regex and entropy scanning for API keys, bearer tokens, JWTs, private keys, and database connection strings before request egress.

- **Build System Simplification** — Removed MCP server and daemon build steps from the release workflow. Single `build.sh` produces one static Go binary.

## 🏗️ Architecture Overhaul

This is a **ground-up rewrite** of the Tzro architecture:

- **Removed the internal DAG execution engine** — The entire `internal/` directory (37 packages, ~1M LOC) has been replaced by 8 focused public `pkg/` packages (~3K LOC). Agents handle their own planning and execution; Tzro focuses purely on token optimization.

- **Removed the MCP server** (`cmd/tzro-mcp`) — The MCP tool interface has been replaced by agent lifecycle hooks that work natively with each agent's hook protocol.

- **Removed the daemon** (`cmd/tzrod`) — Replaced by the transparent reverse proxy (`tzro start`) which runs as a simple foreground process.

- **Removed the dashboard** — Real-time metrics are available via `tzro status` CLI command and the `/metrics` HTTP endpoint.

- **Removed dual-sidecar inference** — Agents use their own LLM providers. Tzro optimizes the traffic transparently.

- **New `pkg/` public library** — All core functionality is available as importable Go packages: `pkg/ast`, `pkg/compactor`, `pkg/dlp`, `pkg/hooks`, `pkg/kvlock`, `pkg/probe`, `pkg/proxy`, `pkg/store`.
