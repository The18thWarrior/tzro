# tzro v0.7.0 Release Notes

**Release Date**: 2026-06-23

---

## ✨ New Features

- **Macro-Nodes** — Pre-built DAG templates for common workflows: codebase exploration, web research, data analysis, and memory ingestion. The engine recognizes these patterns and compiles optimized sub-graphs automatically, reducing prompt complexity for recurring task shapes.

- **Dashboard Overhaul** — The web dashboard has been fully redesigned with a component-based architecture. New interactive DAG visualization lets you click individual execution nodes to inspect their instructions, status, and output. Workflow monitoring, task spotlight with side-panel detail view, sidecar status indicator, and a real-time event feed are all new.

- **Daemon Re-Exec Restart** — Restart the daemon in-place via `tzro restart` or the `/api/restart` endpoint. The daemon replaces itself with a fresh binary copy while preserving the PID, pidlock, and inference sidecar. In-flight tasks are automatically recovered on boot.

- **Durable Inference Metrics** — Inference throughput (tokens/second) and cache hit rates now persist to SQLite instead of ephemeral in-memory counters. Metrics survive daemon restarts and power through a 7-day rolling window with automatic pruning.

- **Gemini CLI Support** — The installer and MCP configuration now detect and configure Gemini CLI alongside existing editor support (Claude Code, Cursor, Windsurf, Copilot).

- **Opt-In SDK & Plugin Installation** — The Antigravity SDK and Hermes plugins are now opt-in during setup. Set `INSTALL_SDK=1` or `INSTALL_HERMES=1` environment variables, or respond to the interactive prompt during installation.

## 🐛 Bug Fixes

- **Installer Memory Corruption** — Fixed a macOS bash 3.2 `malloc` double-free crash caused by `exec`-based stdin redirection during piped installations (`curl | bash`). Replaced with per-command `/dev/tty` reads.

- **MCP Config Overwrites** — Reordered the installation sequence so IDE plugin files are copied before MCP configuration is written, preventing config reloads from overwriting freshly injected server entries.

- **Installation Fallback Prompt** — Fixed a failure path where the interactive fallback prompt did not display when the primary installer could not detect a terminal.

## 🔧 Improvements

- **Dashboard Served at Root** — The dashboard is now served at `/` instead of `/dashboard/`, with unified SPA routing fallback for all static assets.

- **Dashboard Light Mode** — Text and heading styles now maintain sufficient contrast when toggled to light mode.

- **Richer Task List API** — The `/api/tasks` endpoint now returns prompt text, intent type, completion status, and node counts alongside graph data, enabling the new task table UI without additional API calls.

- **Dashboard Lock File** — The daemon writes a `.dashboard.lock` file with PID and port, enabling external tools to discover and connect to the running dashboard.

- **Installer UX Polish** — Improved terminal detection for interactive, piped, and headless installation modes. Added styled section headers, progress feedback, and clearer prompts throughout the setup flow.

---

## Technical Details

- `internal/macronodes` package with `SubDAGTemplate` interface and registry for CodebaseExplorer, WebResearcher, DataAnalyzer, and MemoryIngestionPipeline
- `internal/cli/restart.go` implements re-exec via `syscall.Exec` with PID preservation (ADR-0033)
- `internal/memory/inference_metrics.go` provides `RecordInferenceSample`, `GetAverageTPS`, `RecordCacheEvent`, and `GetDBCacheHitRate` with 7-day auto-prune
- Dashboard decomposed from monolithic `Primitives.tsx` into 15 focused components: DAGView, TaskTable, TaskSpotlight, WorkflowMonitor, EventFeed, StatusBadge, SidecarStatus, and others
- Installer `_tty_read` wrapper replaces `exec 0</dev/tty` pattern to prevent bash 3.2 allocator corruption
