# tzro v0.5.0 Release Notes

**Release Date**: 2026-06-05

---

## ✨ New Features

- **Autonomous Codebase Exploration via Probe Nodes** — Introduced Probe Nodes, a new task type that enables local models to run step-by-step reasoning thought chains to explore codebases, list directories, and search files. Uses Backus-Naur Form (GBNF) grammar schemas to constrain tool outputs, rolling thought compaction to protect context windows, and forced synthesis at budget limits.
- **Model Context Protocol (MCP) Onboarding & Setup** — Revamped the web landing page with a complete Model Context Protocol (MCP) connection guide. This includes step-by-step setup instructions for Claude Desktop, Cursor, and Antigravity, handshake verification procedures, and critical stdio/stderr warnings.
- **Autonomous Agent Offload Policy & Prompts** — Added a visual decision policy and suggested prompt templates (Research, Multi-System Automation, and Codebase Exploration) to guide client-side agents on when to offload heavy tool loops locally.
- **Client Tools & Memory Resources over MCP** — Extended the `tzro-mcp` server to expose dynamic memory resources and client-side tool execution registration over MCP, enabling external agents to delegate tool execution back to the host agent context.

## 🔧 Improvements

- **Execution Hook Resumption** — Enhanced the durability of paused task workflows when resuming execution after human-in-the-loop approval gates or client tool execution pauses.
- **SQLite Memory Persistence** — Improved vector schema representation and keyword indexing logic for local relational graph memories.
- **Robust Path Validation** — Added safe path validation utilities to prevent tools from accessing or modifying files outside of the configured workspace directories.
