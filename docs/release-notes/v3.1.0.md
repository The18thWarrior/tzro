# TZRO v3.1.0 Release Notes

**Release Date**: 2026-10-02

---

## ✨ New Features

- **43% Fewer Agent Turns — Measured** — Instrumented 3-condition comparison (E070) across 9 real coding tasks demonstrates that Guided Tzro uses 43.2% fewer model invocations (63 vs 111) and completes 37.7% faster (125s vs 201s) than a native agent, with the same 9/9 correctness. All 27 executions passed independent grading with full evidence retention. [Instrumented results](../wiki/architecture/instrumented-turn-reduction-results.md).

- **Turn Reduction Benchmark Harness** — `pkg/benchmark/turnreduction` provides a reproducible 3-condition comparison framework (Native/Simple/Tzro) with passive invocation recording, fixture-based independent grading, matrix evaluation, and evidence retention across Go, TypeScript, and Python tasks.

- **Edit Verification Service** — Automatic post-edit verification with file-access sandboxing, partial-write detection, and preset-based test selection. Verifies that edits compile, pass tests, and preserve existing behavior without manual scheduling.

- **Multi-Language Context Packs** — `tzro context` now resolves references across Go, TypeScript/JavaScript, Python, and Rust using Tree-sitter AST adapters. TypeScript barrel re-exports and path aliases, Python relative imports and `__init__.py` re-export chains, and Rust `crate::`/`super::`/`self::` module paths are fully traced with bidirectional call graph extraction.

- **Symbol-Anchored Context** — `tzro context --symbol <name> [--file <path>]` surgically assembles context around a specific symbol declaration. When multiple symbols share the same name across files, `--file` provides disambiguation.

- **Predictive Test Selection** — `tzro test --impact [--staged|--unstaged|--all]` analyzes the blast radius of code changes, identifies affected test files across Go (`go test`), TypeScript (`jest`/`vitest`), and Python (`pytest`), and runs only the relevant tests with compacted output. Comment-only diff hunks are filtered out. Config or fixture changes trigger fallback to broader suites.

- **Session Pause/Resume** — `tzro pause [description]` snapshots agent work for later resumption. `tzro resume [id]` loads the session and renders an interactive resumption dashboard showing git branch divergence, modified file drift, stale evidence markers, and shifted symbol lines. Supports `--format tty|plain|json`.

- **Shell Integration** — `tzro shell init [zsh|bash]` installs lightweight preexec/precmd hooks that capture development commands into SQLite with sub-millisecond overhead. Commands are filtered through a strict development allowlist, and sensitive credentials (API keys, bearer tokens) are automatically redacted before storage.

- **Git Hook Manager** — `tzro hook install pre-commit` installs an advisory pre-commit hook that displays staged impact analysis without blocking commits. Existing hooks are backed up to `.tzro.backup` and chained. `tzro hook uninstall` restores the original. Works across standard repos, linked worktrees, and submodules.

- **Exact BPE Tokenizer** — Thread-safe `cl100k_base` and `o200k_base` token counting via `tiktoken-go` with UTF-8-safe truncation. Used internally for precise budget enforcement in context packs.

- **Repository Configuration** — `.tzro/context.yaml` (Schema v1) provides per-repo defaults for token budgets, traversal depth, tokenizer selection, language priorities, and custom command allowlists. Thread-safe with mtime-cached loading.

## 🔧 Improvements

- **Enhanced Impact Analysis** — `tzro impact` now supports `--staged`, `--unstaged`, and `--all` scopes for granular control. New `--format tree|json|markdown` output with ANSI hierarchical tree rendering via Lipgloss. Comment-only diff hunks are filtered to prevent false positives.

- **Knapsack Budget Packing** — Context pack assembly now degrades over-budget references to signature stubs (`{ /* body omitted to fit budget */ }`) rather than dropping them entirely, preserving awareness of more symbols within tight budgets.

- **MCP Protocol v2025-06-18** — Added `tzro_get_context_pack` and `tzro_get_impact_report` MCP tools with structured output schemas and typed result payloads. Protocol version negotiation supports both `2024-11-05` and `2025-06-18`.

- **Context Pack Output** — `--format json` for machine-readable output, `--output <path> [--force]` for atomic file exports.

- **Command Event Store** — SQLite storage for shell command capture with retention pruning by count and age, exit code correlation, and workspace/session scoping.
