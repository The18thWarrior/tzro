# tzro v0.8.0 Release Notes

**Release Date**: 2026-07-02

---

## ✨ New Features

- **Local Code Generation (`tzro_code`)** — Generate or modify source files by providing a natural language spec and a file path. The engine gathers context from the target file and its neighbors, classifies task complexity, and routes to either single-pass or two-phase draft generation — all using the local model with zero cloud API calls.

- **Compilation Quality Gate** — Generated code is automatically validated with language-appropriate compilation checks (Go, TypeScript, Python, JavaScript). When compilation fails, the engine spawns a repair node with structured error context and language-specific reference patterns to self-correct — up to 3 attempts before reporting.

- **Diff-Based File Patching** — When updating large existing files, the code generation pipeline produces targeted diff patches instead of full-file rewrites. Only the relevant sections change, preserving the rest of the file intact.

- **Edge Thought-Driven Repair** — The neural traversal system now powers code repair workflows. Compilation failures trigger edge thought evaluation, which dynamically spawns repair nodes into the DAG — the same mechanism used for exploration now handles automated code correction.

- **Codegen Benchmark Conditions** — The comparison framework now supports codegen-specific evaluation conditions (`tzro_code`, `tzro_draft`, `cloud_code`) with language-specific seed files and pseudocode task definitions for measuring code generation quality across execution modes.

- **Documentation Site** — Interactive documentation page with sidebar navigation, scroll-spy tracking, and code copy functionality at the project website.

## 🔧 Improvements

- **Complexity-Based Routing** — Code generation tasks are classified by complexity (spec length, file size, language) and routed to the optimal pipeline: simple tasks use direct single-pass generation, complex tasks use a two-phase draft-then-refine approach.

- **Module Context Extraction** — For Go files, the code generation prompt now includes package-level type signatures, function declarations, and interface definitions from the target directory — giving the model awareness of the surrounding codebase.

- **Exemplar Injection** — Language-specific code exemplars are injected into generation prompts to bias the local model toward idiomatic patterns, improving output quality for Go error handling, TypeScript types, and Python conventions.

- **Failure Dampening Initialization** — The executor now automatically initializes mutation budgets when unset by the planner, preventing unbounded node spawning. Consecutive failure counters are tracked per-task and reset on successful activation.

- **MCP Tool Consolidation** — Specific tools consolidated into `tzro_api` and `tzro_model` dispatchers, simplifying the tool surface for client integrations.

- **Branding Update** — Updated to TZRO branding with new logo assets across the website and dashboard.

## 🐛 Bug Fixes

- **Background Task Crash Recovery** — Added `recover()` to all background task goroutines in the daemon server, preventing panics in background services from crashing the entire daemon.

- **Filesystem Tool Safety** — Read access to temporary directories in codegen is now properly allowed, and legacy test cases that relied on unsafe path assumptions have been removed.

## Technical Details

- New `internal/codegen/` package: context gathering, prompt building, diff mode, compilation quality gate, module context extraction, exemplar injection, complexity classification, and repair hooks (~2,100 lines)
- `internal/codegen/codegen_diff.go`, `diff_apply.go`, `diff_prompt.go`, `diff_types.go`: Structured diff-based file patching pipeline
- `internal/codegen/compilation.go`, `compilation_hook.go`: Language-specific compilation validation with edge thought-driven repair node spawning
- `internal/codegen/module_context.go`: Go package-level type signature extraction for prompt injection
- `internal/codegen/quality_gate.go`: Structural quality evaluation for generated code
- `internal/comparison/conditions.go`: Codegen benchmark conditions with tier-based routing (`ConditionTzroCode`, `ConditionTzroDraft`, `ConditionCloudCode`)
- `internal/executor/edge_thought_impl.go`: Edge thought inference implementation with GBNF-constrained JSON schema
- `internal/executor/neural_traversal_test.go`: Comprehensive test coverage for dynamic node spawning, failure dampening, and mutation budgets
- `internal/tools/filesystem.go`, `pathvalidator.go`, `validate.go`: `write_file` tool with path validation, backup-on-overwrite, and binary rejection
- `cmd/tzro-mcp/tools.go`: Tool consolidation into `tzro_api` and `tzro_model` dispatchers, `classify_complexity.go` for codegen routing
