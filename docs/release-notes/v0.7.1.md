# tzro v0.7.1 Release Notes

**Release Date**: 2026-06-25

---

## ✨ New Features

- **Quick Peek File Sampling (`peek_file`)** — Introduced a low-cost file sampling tool that retrieves only the first 20 lines of a file, encouraging fast verification without context bloat.
- **Smart Directory Noise Filtering** — The file system tools now automatically filter out OS metadata (`.DS_Store`), dependency folders (`node_modules`, `.git`), build artifacts, and database/log files to ensure cleaner agent contexts.
- **Directory Extension Profiling** — Directory listings now summarize files mathematically by extension (e.g., "45 .go, 8 directories"), giving the agent a clean high-level view of directories.
- **Context Compaction API (`tzro_compact`)** — Exposed the 5-layer context compaction pipeline as an MCP tool for on-demand context token footprint optimization.

## 🐛 Bug Fixes

- **Dashboard UI Crashes** — Fixed rendering issues in the web dashboard by adding null-safety boundaries when displaying node statuses and logs in the DAG view.
- **Test Isolation** — Corrected local inference model startup during test execution to prevent unit tests from adopting or leaking background daemon `llama-server` processes.

## 🔧 Improvements

- **Comprehensive Architecture Documentation** — Created a dedicated `docs/ARCHITECTURE.md` guide explaining the Strategist-vs-Tactics paradigm, topological compiler sort, compaction layers, and Go SDK custom tool registration.
