# tzro v0.4.0 Release Notes

**Release Date**: 2026-06-04

---

## ✨ New Features

- **Native Agent Plugins (Hermes & Antigravity)** — Integrated native client plugins allowing durable task execution to run completely locally, routing client tool calls directly inside the host agent context without external cloud round-trips.
- **Extended Local Toolspace** — Added local utility tools including semantic web search, model management (catalog listing, activation/switching), text completion, and intent classification directly available to local agents.
- **Real-Time Task Monitoring & Resource Subscriptions** — Added standard Model Context Protocol (MCP) resource endpoints and subscriptions, allowing clients to monitor task graphs and individual execution node outputs in real-time.
- **Enhanced Web Dashboard** — Revamped web UI dashboard with responsive mobile layouts, drawer navigation, and robust visualization for memory graphs and task compilations.

## 🔧 Improvements

- **MCP Protocol Compliance** — Integrated standard protocol initialization and handshake support for stdio clients to ensure strict compliance with standard MCP host implementations.
- **Robust Tool Parameter Coercion** — Added numeric and string parameter coercion rules during task execution to prevent local LLM tool call argument mismatch and hallucination.
- **Dynamic Client Tool Dispatch** — Improved the tool dispatch loop to map notifications dynamically and resolve client-side tool requests matching Python execution client specifications.
