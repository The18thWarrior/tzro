# tzro v0.7.3 Release Notes

**Release Date**: 2026-06-27

---

## ✨ New Features

- **Benchmark Comparison Framework** — Compare execution quality across local, cloud, and cooperative modes with structured scoring. Run `tzro compare` to evaluate task performance with automated LLM judging, per-criterion breakdowns, and cost/latency reports.

- **Weighted Circuit Breaker** — Tasks now have intelligent time budgets based on their node composition. The engine gracefully terminates runaway tasks while preserving completed work and always producing a final synthesis — no more tasks running indefinitely.

- **Content-Aware Truncation** — Probe exploration results are now truncated intelligently before synthesis: code preserves function signatures and doc comments, tabular data keeps sample rows, and prose uses middle-out elision. This prevents context window overflow while retaining the most valuable information.

## 🔧 Improvements

- **Probe Minimum Step Budget** — Probes no longer terminate prematurely when the local model signals readiness too early. An adaptive floor (min of 8 steps or half the budget) ensures thorough exploration before synthesis.

- **Plan Repair Pipeline** — When the local planner hallucinates non-existent tool names, the engine now surgically repairs the graph by replacing invalid nodes with probe nodes — reducing unnecessary cloud escalations and improving local-only reliability.

- **Tool Name Classification Fallback** — At execution time, hallucinated tool names are classified to the nearest real tool using local inference instead of failing immediately. Near-miss names like "search_file" are resolved to "search_files" automatically.

- **Configurable Compaction Levels** — Probe nodes now support three compaction levels (preserve, moderate, aggressive) to control how aggressively tool outputs are summarized during the thought chain. Default changed to "preserve" to prevent quality loss.

- **Cloud Escalation Control** — Privacy-level checks for cloud escalation are now cleaner: confidence checks are skipped entirely when cloud is blocked, avoiding misleading error messages under strict-local mode.
