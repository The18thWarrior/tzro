# tzro v1.0.1 Release Notes

**Release Date**: 2026-07-23

---

## ✨ New Features

- **SQLite-Backed Query Cache & SQL Query Language for Cached Data** — Replaces JQ-based cache querying with a high-performance, disk-backed SQLite query engine (`introspect_cache`, `sql_cached_data`). Tabular tool outputs and CSV datasets are automatically profiled and stored in SQLite tables for fast, structured relational queries (ADR-0048, ADR-0051).
- **Analyze Nodes & Data Profiler** — Introduces dedicated Analyze Nodes (`0050-analyze-node.md`) with automatic dataset profiling, schema extraction, column name sanitization, and reserved SQL keyword matching (`0049-data-profiler-and-cache-bridge-node.md`).
- **CompactPreserve Semantics** — Prevents data loss during compaction in Analyze Nodes by preserving tabular query results and cache IDs when outputs exceed context budget floors (ADR-0052).
- **Analytical Evidence Collection** — Automatically captures query outputs and tabular evidence from analyze nodes, feeding structured context directly to downstream DAG nodes and recall tasks (ADR-0053).
- **Self-Contained Task Short-Circuiting & Lifecycle Tracking** — Bypasses redundant probe discovery loops for self-contained prompts, enables inline prompt context for direct synthesis when context files are omitted, and tracks task lifecycle states across SQLite execution tables (ADR-0054).

## 🐛 Bug Fixes & Refinements

- **SQLite Reserved Keyword & Envelope Sanitization** — Fixed query reliability issues by sanitizing envelope field names and column names to match SQL table schemas, preventing syntax errors on reserved keywords.
- **Quote-Aware CSV Parsing** — Improved CSV cache parsing to handle quoted strings, commas, and space-delimited headers reliably.
- **Probe Direct Synthesis Fallback** — Corrected direct synthesis handling when prompt context is supplied inline without a context file.
