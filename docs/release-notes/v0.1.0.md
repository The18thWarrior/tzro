# tzro v0.1.0 Release Notes

**Release Date**: 2026-05-28

---

## ✨ New Features

- **Durable Agentic Engine** — Bootstrapped the local-first execution engine designed to coordinate complex multi-system automations with persistent SQLite task/workflow state tracking.
- **Relational Knowledge Graph Memory** — Implemented semantic memory traversal using Hybrid Vector Search (combining local keyword query filtering and ONNX cosine similarity matching) for neighborhood multi-hop neighborhood searches.
- **Kahn Graph Compiler** — Enabled deterministic parallel compilation of multi-step execution graphs into deterministic parallelized layers with cycle detection using Kahn's topological sorting algorithm.
- **WASM Sandboxed Micro-Skills** — Added secure WebAssembly sandboxing for executing custom, isolated, resource-constrained helper binaries on the local host.
- **Model Context Protocol (MCP) Host** — Created a stdio-based tool server execution manager to resolve dynamic catalogs, secure delegated secrets, and guarantee valid tool schemas via logit-level GBNF grammar constraints.
- **Bubble Tea Terminal Client** — Shipped a fullscreen interactive console dashboard CLI utilizing Bubble Tea for real-time task inspection, logs viewing, and offline database inspection.
- **React Web Dashboard** — Designed a modern, highly responsive web dashboard featuring real-time Server-Sent Events (SSE) task streaming, a gorgeous interactive graph canvas, and robust system configurations control.

## 🐛 Bug Fixes

- **Vite Web Dashboard Compilation** — Resolved 13 TypeScript and ESLint problems in the React web client (including type-safety casting for `unknown` exceptions, missing properties in notification models, and eliminating useless assignments).

## Technical Details

- **Language & Storage**: Built in Go using pure SQLite for lightweight, transactional local-first persistence.
- **Frontend Stack**: Developed as a single-page React app bundled with Vite and TailwindCSS for ultra-fast, clean, and dynamic styling.
- **Sidecar Integration**: Connects locally to static GGUF local model execution helpers (`llama-server`) for fast, local-first inference.
