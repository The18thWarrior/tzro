# tzro v0.1.0 Release Notes

**Release Date**: 2026-06-02

---

## ✨ New Features

- **Durable Local-First Execution Engine** — Native coordination of complex, long-running Tasks and Workflows via persistent SQLite state checkpointing, ensuring executions resume cleanly across daemon crashes or system restarts.
- **Kahn Graph Compiler & Sorter** — Automatically translates strategical natural language instructions into topologically sorted parallel execution levels, executing independent step nodes concurrently in separate goroutines.
- **Relational Knowledge Graph Memory** — High-performance enterprise context memory that models systems, facts, and links in a local SQLite database, using Hybrid Vector Search (FTS5 keyword canditates + local ONNX cosine similarity ranking) for Neighborhood Multi-Hop search traversal.
- **Stdio MCP Host Gateway** — Dynamic integration of third-party APIs over standard standard I/O (stdio) with thread-safe process self-healing, automatic recovery on crash, and recursively-resolved environment-delegated secrets.
- **Bubble Tea Terminal TUI Dashboard** — Fullscreen interactive terminal console supporting offline read-only database navigation and real-time StreamBus event log telemetry monitoring.
- **Vite React Web Control Center** — Premium web interface streaming active task execution progress, token usage metrics, and node-edge networks over Server-Sent Events (SSE).
- **Synchronous DAG Execution Hooks** — Lightweight middleware hooks (`BeforeLevel`, `AfterLevel`, `BeforeNode`, `AfterNode`) enabling developers to validate, pause, skip, abort, or dynamically mutate task parameters and outputs.

## 🔧 Improvements

- **SCT Compiler Expansion** — Surgery-split Strategist-Compiler-Translator execution pipeline that expands Strategic planning graphs locally, injecting Backus-Naur Form (GBNF) logit-level constraints and deterministic child execution nodes.
- **5-Layer Context Compaction** — Optimizes attention footprints by compressing bulky tool outputs (binary headers, homogeneous TSV JSON tables, and tree-flattened KV layers) by up to 85%, preventing local slot thrashing.
- **Disk-Backed SQLite JQ Cache** — Intercepts execution payloads exceeding 12KB, saving them to SQLite and exposing JQ query guidelines to the local tactician, keeping model KV memory clean.
- **KV Cache Preemption** — Background tasks seamlessly save active context states to disk to give instant sub-450ms attention priority to concurrent interactive chat threads.

## 🐛 Bug Fixes

- **Numeric Coercion and Upstream Resolution** — Fixes parameter extraction sign mismatches and dynamically parses upstream numerical references, resolving parameter mismatches in financial billing runs.
- **SQLite Database Schema Migrations** — Dynamically alters pre-existing database files on disk to add missing ONNX embedding columns without drop-corrupting existing data.

## Technical Details

- **Maintainability Decomposition**: Decomposed monolithic hot-spots (`internal/benchmark/runner.go` and `internal/memory/memory.go`) into dedicated modules (`vfs`, `matcher`, `mock`, `graph_rag`, `memories`, `workflows`, `models`), bringing all core files strictly under the 1,000-line maintainability threshold.
- **Parallel Benchmarking**: Benchmarks run in parallel using a bounded worker pool (`errgroup`) with thread-safe default transport intercept locking.
