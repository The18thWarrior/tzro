# TZRO v1.0.2 Release Notes

**Release Date**: 2026-07-29

---

## ✨ New Features

- **Spec Compliance Gate for Codegen** — Automatically evaluates generated code against spec requirements post-compilation using local model logit constraints, triggering targeted code regeneration if any required behavior is missing.
- **Symbolic Callgraph Traversal (`tzro_query_callgraph`)** — Introduces AST-driven symbolic callgraph extraction and query tools using `gotreesitter`, enabling deep call-site investigation, function declaration lookups, and reference traversal across multi-language codebases (Go, Python, TypeScript/TSX, JavaScript, Rust, and Java).
- **Probe Execution Resilience & Exploration Queue** — Features candidate location deduplication and inline SQL query extraction to eliminate redundant exploration loops during codebase analysis.
- **Structured Execution Envelopes** — Captures and persists execution task metadata, token usage metrics, and node status details across all MCP tool calls and responses.
- **Task Cancellation Support** — Enables context-aware task cancellation across API, CLI, and MCP endpoints.

## 🐛 Bug Fixes

- **Synthesis Fallback Sanitization** — Fixed prompt augmentation for ADR references, stripped internal thinking tags, and added synthesis fallback sanitization.
- **Absolute Path Enforcement** — Enforced absolute file paths in compilation passes and prevented compaction of referenced dynamic bindings.
- **Configuration Path Fallback** — Added fallback to user home directory for configuration paths to prevent ghost files in the current working directory.

## 🔧 Improvements

- **Append-Only Conversation Sliding Window** — Replaced sliding window resets with an append-only conversation sliding window to maximize KV cache reuse during multi-step probe execution.
- **Tiered Codegen Repair Escalation** — Implemented structured repair loops with compilation-gated escalation and failure dampening for code generation tasks.
