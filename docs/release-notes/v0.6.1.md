# tzro v0.6.1 Release Notes

**Release Date**: 2026-06-15

---

## ✨ New Features

- **PDF Parsing** — Read PDF files directly with the `read_file` tool. The engine extracts native digital text and runs OCR on embedded images using the local vision model or system tesseract — no data leaves your machine.

- **Local Vision / Multimodal Inference** — The engine now supports multimodal prompts (text + images) via the OpenAI-compatible vision API format. A companion vision projector model (mmproj, ~534 MB) is auto-downloaded alongside the default Gemma 4 E4B model to enable local image understanding.

- **Strict-Local Privacy Mode** — Set `privacyLevel: "strict-local"` in your config to hard-block all cloud API calls. Even when the local model fails or confidence is low, no data is ever sent to external providers. Ideal for air-gapped or compliance-sensitive environments.

- **App Package Manager API** — Install, list, and uninstall third-party tool apps via new HTTP endpoints (`/api/apps`). Apps bundle WASM tools and optional MCP server daemons that auto-register with the engine and persist across restarts.

## 🔧 Improvements

- **Daemon Task Proxying** — The MCP server now proxies `tzro_run`, `tzro_resume`, and `tzro_hook_approve` to the running daemon via SSE event streaming, giving real-time execution feedback instead of fire-and-forget.

- **Dynamic Port Allocation** — The daemon server now auto-selects an available port when the default is occupied, writing the active port to `.tzro/.daemon.port` for automatic discovery by the MCP server.

- **Richer Task Status** — `tzro_status` now surfaces `waiting_for_approval` status alongside `waiting_for_client`, with actionable instructions on how to unblock the task.

- **Model Swap Vision Auto-Setup** — Swapping to a vision-capable model automatically downloads its companion mmproj in the background so local vision features are immediately available.

- **Installer Hardening** — The install script now downloads real model weights (Gemma 4 E4B ~3.9 GB + vision projector ~534 MB) instead of placeholders, with atomic `.download` temp files to prevent partial-download corruption.

---

## Technical Details

- Multimodal message support via `ContentPart` / `NewMultimodalMessage` in the inference routing layer
- `MessagesToMaps` now produces `[]map[string]interface{}` to support both text-only and multimodal content formats
- `CompanionFile` and `CompanionMMProj` fields added to the model catalog for automatic vision projector management
- `config.GetMMProjModelPath()` auto-detects mmproj files in the models directory
- `config.GetDaemonURL()` / `WriteDaemonPort()` / `RemoveDaemonPort()` manage dynamic daemon port discovery
- `LoadInstalledApps()` re-registers WASM tools and MCP daemons for all active packages on startup
- Privacy guard checks added to 5 cloud-fallback code paths in the inference router and confidence engine
