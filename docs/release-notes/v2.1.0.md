# Tzro v2.1.0 Release Notes

**Release Date**: 2026-09-09

---

## ✨ New Features

- **Task Context Assembly (`tzro context`)** — Assembles ranked, token-budgeted context packs containing symbol definitions, TypeScript path alias resolutions (`@/*`, `~/*` from `tsconfig.json`), and AST call graphs in a single sub-second turn. Replaces 5–10 exploratory agent turns with a single <2k token pack.

- **Pre-Edit Change Impact Analysis (`tzro impact`)** — Analyzes the AST call graph and package dependency hierarchy to calculate blast radius before code edits. Identifies direct callers, downstream dependent modules, and existing unit/integration test coverage for affected code or uncommitted git changes.

- **Unified Local Evidence Search (`tzro search`)** — Heterogeneous local search across source code, markdown documentation, architecture decision records (ADRs), specs, logs, and stored artifacts in <10ms with content-addressed deduplication and AST span extraction.

- **Agent Session Continuity (`tzro session`)** — Captures active objectives, architectural decisions, executed checks, and constraints into portable Schema v2 manifests. `tzro session status` validates freshness against git tree state, preventing stale evidence and eliminating multi-megabyte transcript re-reads across agent handoffs.

- **Evidence Contract Compactor (`tzro compact --run`)** — Direct process execution wrapper capturing verified exit codes, enforcing a strict 10-line root-cause inline diagnostic cap, and archiving full failure output into SQLite with an expansion hash for instant on-demand retrieval (`tzro expand`).

- **System Diagnostics (`tzro doctor`)** — Synthetic health check inspecting loopback proxy route interception, upstream provider latency (Anthropic, OpenAI, Gemini), SQLite FTS5 extension capability, and 5-harness agent lifecycle hook registrations.

- **Signal Density Benchmark Suite (`tzro bench signal-density`)** — Empirical benchmark measuring task signal density per token ($S = \text{Recall} / \text{Tokens}$) with strict spend limit circuit breakers (`--max-cost`) and structured comparative reporting.

- **Offline Context Explainability (`tzro inspect explain`)** — Replays context pack generation from saved trace IDs and explains candidate inclusion, BM25 ranking, and stage-by-stage omission reasons with zero cloud token consumption.

- **Zero-Cloud DLP Policy Engine (`.tzro/privacy.json`)** — On-device workspace policy engine supporting allow/deny/redact/block rules with regex and Shannon entropy secret scanning before request egress.

- **Schema v2 Multi-Workspace Store** — SQLite database schema upgrade featuring multi-workspace isolation, configurable LRU artifact eviction, quota enforcement, and diagnostic trace persistence.

## 🔧 Improvements

- **`tzro expand` Line Slicing** — Added `--lines <start-end>` flag to slice specific line ranges from stored artifacts and elided code bodies, minimizing token retrieval.

- **FTS5 Graceful Fallback** — Automatically detects SQLite FTS5 availability and falls back seamlessly to indexed lexical search when running without CGO or on platforms lacking FTS5.

- **Proxy Fidelity & Usage Tracking** — Preserves unrecognized provider fields, handles tool call IDs reliably across streaming turns, and tracks granular input/output/cache token metrics per request.

- **Website & Documentation Refresh** — Modernized website landing page, documentation, and `llms.txt` to fully document all v2.1.0 Context & Evidence capabilities with copyable CLI snippets.
