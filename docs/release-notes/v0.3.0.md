# Tzro v0.3.0 Release Notes

**Release Date**: 2026-06-03

---

## ✨ New Features

- **MCP Server Mode** — Expose tzro durable task execution over the Model Context Protocol (MCP) using the new `tzro-mcp` binary, allowing integrations with Claude Desktop, Cursor, and Nous Hermes to run tasks, check status, list records, and register tools.
- **Pluggable Inference Backend** — Swap out local model sidecars (`llama-server`) for remote OpenAI-compatible endpoints (Ollama, LMStudio, OpenAI) to execute strategic graph planning.
- **Client-Side Tool Dispatch** — Intercept task execution when encountering client-run tools, pausing durably to request local client outcomes and resuming seamlessly upon submission.

## 🔧 Improvements

- **Developer Setup Manual** — Created a comprehensive MCP Setup Guide (`docs/mcp-setup-guide.md`) detailing build commands, Claude/Cursor host configurations, stdio pipe safety, and client tool registrations.
- **Diagnostics and Health Checks** — Added `/health` route to the HTTP server for backend reachability probes and release pipeline integration testing.
