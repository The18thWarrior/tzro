# Edge Thought and Activation Threshold — Neural Edge Traversal

The static DAG execution model (ADR-0001) and the Probe Node (ADR-0019) are unified into a single dynamic execution model where every DAG edge can carry an **Edge Thought** — a compact reasoning state generated by the Local Model — and every node has an **Activation Threshold** — a sufficiency gate that triggers dynamic node spawning when the Edge Thought's goal confidence falls below the threshold.

This deprecates the Probe Node and Thought Chain as distinct concepts. The Probe's internal tool loop is replaced by dynamic node spawning: each tool call becomes a real, checkpointed DAG node with full durability, rather than a hidden internal step. The pre-computed topological level loop is replaced by an event-driven ready queue where nodes fire as soon as their dependencies are satisfied.

## Status

Accepted. Supersedes ADR-0019 (Probe Node and Thought Chain Execution).

## Considered Options

- **Keep Probe Nodes as a special type alongside Edge Thoughts.** Rejected — the Probe exists precisely because static DAGs can't react to runtime discoveries. Edge Thought + Activation Threshold generalizes that capability to all nodes, making the Probe redundant. Maintaining both creates two competing mechanisms for the same problem.

- **Cloud Planner involved in runtime mutations.** When a node needs to spawn, call the Cloud Planner for a micro-plan. Rejected — adds a cloud round-trip per mutation, violates the Local-Default principle (ADR-0010), and the Local Model already handles single-step tool selection in the Probe's Thought Chain. Spawn specs are single-step decisions, not multi-node plans.

- **Pre-computed level iteration with mutation patches.** Keep the existing level loop but patch `levels[idx+1:]` after mutations. Rejected — maintaining two systems (pre-computed levels + mutation patches) is more complex than a single ready queue that evaluates readiness lazily. The ready queue IS Kahn's algorithm executed incrementally.

- **Always-on Edge Thoughts for all nodes.** Every node generates an Edge Thought regardless of configuration. Rejected — deterministic pipeline nodes (query → save → notify) don't benefit from reasoning overhead. Opt-in via Activation Threshold preserves zero-overhead for simple workflows.

## Consequences

- **The execution loop changes fundamentally.** The `for levelIdx, level := range levels` loop in `ExecuteGraph` is replaced by a ready queue that fires nodes when all dependencies are satisfied. This affects telemetry, progress reporting, and the hook system (`BeforeLevel`/`AfterLevel` are removed, `OnEdgeTraversal` is added).

- **Graph mutation at runtime.** This deliberately crosses the line drawn in ADR-0001 ("graph structures must be compiled beforehand"). The safety model is: per-task mutation budget (bounded spawns), consecutive failure dampening (inhibits runaway cascades), and incremental Kahn re-sort with cycle detection after every mutation.

- **Probe Node backward compatibility.** Existing DAGs emitting `type: "probe"` are silently treated as action nodes with a high Activation Threshold (0.8) and allocated mutation budget (maxSpawns: 15). No breaking change to the planner's output schema.

- **Edge Thoughts are target-gated.** The target node's Activation Threshold determines whether an Edge Thought is generated on incoming edges. A threshold of 0.0 disables Edge Thought generation entirely, preserving zero-overhead for deterministic nodes. The Kahn Compiler defaults thresholds by node type: 0.0 for deterministic/synthesis, 0.7 for action nodes.
